# 使用流程

## 早晨

1. 如果昨晚保存了“明日第一动作”或专业课“下一准确起点”，打开网站后只显示这个真实断点；首屏任务卡、当前任务选择和状态提示始终指向同一项，点击“直接开始5分钟”后才会写入当前任务并开始计时。
2. 如果没有可用断点，网站不编造内容，直接显示正常计划；需要核对全天安排时再查看“今日时间表”。
3. 只有补录时间、调整目标、查看历史或处理备份时，才展开对应折叠区。

## 学习过程中

1. 在未开始的正式学习任务上点击“先做5分钟”，网站会选中该任务、给出一个最小动作并直接开始5分钟倒计时。
2. 5分钟结束后只选择“继续25分钟”或“记录卡点并暂停”；暂停或离开页面后可从同一任务点击“继续刚才的5分钟”。
3. 专注中切换页面、最小化或设备休眠时会自动暂停；回来后直接点“继续当前任务”。离开期间不计时，任务太难时可缩小为一个最小动作后继续。
4. 正常专注结束时点击“结束并记录”。
5. 当前项完成后，驾驶舱会切换到下一项可执行任务；它只提供建议，不会在未点击时启动计时。
6. 保存真实结果后，网站按现有验收规则自动完成对应任务：
   - 英语记录真题阅读；单词继续在背词 App 中完成，不重复登记。
   - 722/844 记录知识单元、掌握等级、闭卷结果、缺口和下一步。
   - 政治记录章节、内容、真实时间和已做题型。
   - 专业课输出必须留下题目、闭卷事实和结构结果。
7. 状态调整、编辑说明和直接补记结果保留在任务右侧“更多”中。
8. 起居、午休、洗澡和自由时间收在“生活安排”；锻炼单独保留。
9. 未使用计时器的纸质学习可从“执行设置与补录”补录时间；生活与训练不计入有效学习时长。
10. 结束 722/844 的正常专注且该科尚无闭卷产物时，网站会直接打开原有三项记录；不会把专注时长当作产出。

## 到期复盘

1. 复盘在其他地方完成时，可以只把这里的数量作为提醒；如需使用面板内复盘，当前只处理队列第一条，点击“开始5分钟遮挡复述”进入现有专注模式，已有未结束专注时不会覆盖或重复计时。
2. 复述后只填写三行：`记住了=`、`遗漏了=`、`下一步=`；没有明显遗漏时填写“无”。
3. 三行未填完整时不能点击“通过／部分通过／未通过”，专注时间不能代替闭卷证据。
4. 填完后才显示上次保存的主要遗漏和下一起点，避免作答前得到提示。
5. “部分通过”仍安排24小时内短时重测；“未通过”仍重置D0；保存后自动进入下一条到期复盘。

## 状态很差时

1. 点击“状态很差？进入今日保底执行”，完整时间表会暂时隐藏，但原计划和任务状态不会改变。
2. 页面一次只显示一步：一个专业课闭卷产物、英语最低动作、政治最低动作、两句话收工；滚动复盘仅保留提醒和手动入口，不进入保底接管。
3. 每一步仍使用正式验收：专业课必须保存真实闭卷产物，英语和政治必须保存真实结果，复盘必须真实提交结果。
4. 保底闭环只防止当天归零，不替代正常计划；状态恢复后点击“退出保底，返回正常计划”继续原安排。

## 晚上

1. 处理今日到期与逾期复盘，未验收内容不得提高掌握等级。
2. 每个关键时间块结束后，驾驶舱只接管一个尚无正式结果的缺口：午间检查英语与722，下午检查844与到期复盘，晚间检查政治与闭卷产物。
3. 关键缺口按英语、722、844、复盘、政治、闭卷产物顺序收敛；保存有效结果后自动进入下一项。训练、生活时间和未结束的专注轮次不会被打断。
4. 完成“今日学习记录”，并核对“今日闭卷产物”是否已保存；该提示只反映正式记录，不阻止收工。
5. 主动打开收工区且两项内容为空时，网站会依据已保存的正式结果和下一准确起点生成可编辑草稿；人工草稿和当天已保存记录不会被覆盖，点击“一键收工”后才正式写入历史。
5. 需要时展开“今日详情”导出快照或查看历史；完整 JSON 备份仍在“系统工具”中。

## 晚间止损

1. 工作日21:40、周日20:30后，不再展开全天欠账；最多保留一个专业课闭卷产物和英语/政治中的一个支持任务。
2. 每项先做5分钟，需要时只继续一个25分钟闭环；网站复用现有计时和结果记录，不新建第二套流程。
3. 工作日22:30、周日21:30后，只显示“两句话收工”，不再启动新任务。
4. 剩余缺口保持未完成；网站只把最高优先级未完成项填入现有“明日第一动作”草稿，点击“一键收工”后才正式保存。

## 周末

1. 查看最近7天的真实学习时间、任务完成和记录保存情况。
2. 重点检查英语稳定性、政治持续性、722/844推进、闭卷输出和D1/D3/D7/D14/D30复盘。
3. 只根据多日事实调整下一阶段，不因单日波动频繁改计划。
## 专注结束后的记录

1. 英语阅读、722、844、政治和专业课输出结束专注后，网站直接打开对应的现有结果记录，不再先填写一遍通用收尾。
2. 计时会先结算一次，再进入结果记录；结果是否有效、任务是否完成，仍由原有证据规则判断。
3. 普通任务或对应结果入口不可用时，继续使用“本轮完成了什么 / 下一步做什么”的两句话收尾。
## 今日计划总览

1. 首页只通过“现在做什么”启动当前任务；“今日时间表”默认折叠，仅显示已完成数量、当前任务和剩余数量。
2. 需要查看全天安排、切换任务、修改状态或补录结果时再展开时间表，原有任务和记录功能均保留。
3. 从驾驶舱进入722或844结果记录时，时间表会自动展开并显示原有三项记录。
## 下一项学习任务

1. 驾驶舱“下一项学习任务”只显示尚未完成的正式学习任务，不再把复盘队列插入学习顺序。
2. 到期与逾期复盘数量仍作为提醒显示，复盘页面和手动入口保持不变。
3. 时间表任务行和“下一项学习任务”会复用驾驶舱的准确起点；722、844 有已保存的“下一准确起点”时优先显示该动作，避免展开时间表后重新判断从哪里开始。
4. 时间块结束后的“关键缺口”和“晚间止损”同样复用该准确起点；没有正式保存断点时才显示原有保守动作，接管顺序和完成规则不变。
5. 英语阅读、政治和专业课输出也会分别复用正式保存的“下一起点”或“下一步”；未来记录、空值和占位内容不会被当作准确起点。
6. 专业课输出断点按722与844严格隔离；任务无法明确归属单科时不复用历史输出断点，继续显示原计划动作，避免串科。
7. 今日计划明确提供的 `nextStart`、任务最低动作和人工修改说明优先于历史断点；完成标准只用于验收，不会被误当作开始动作。
8. 历史正式断点会在界面标明来源日期，人工修改也会明确标识；5分钟目标和明日动作仍只使用纯动作，不把来源文字写入学习记录。
9. 保存真实结果后，回执会直接提供“先做下一项5分钟”；只有点击后才切换任务并启动计时，选择“稍后再做”只关闭回执，当日任务全部完成时则只提示收工。
10. 驾驶舱只接受一个统一执行状态：未结束专注或恢复优先，其次是主动保底模式、昨日交接、晚间收工、关键缺口，最后回到正常计划；多个条件同时出现时不会依赖重复渲染互相覆盖。
11. 当前任务ID、标题、说明和主按钮来自同一个显示模型，并由唯一函数写入驾驶舱；如果按钮任务与显示任务不一致，网站会禁用动作而不是切换到错误任务。
12. 点击驾驶舱主按钮时，网站会重新核对当前执行状态与屏幕上已显示的任务、模式和动作；如果状态已经变化，只刷新并提示重新确认，不会继续执行过期动作。
13. 展开今日时间表后，每个任务的主按钮也使用同一套动作校验；任务状态已经变化时会刷新任务行，不会按旧按钮启动、结束或完成任务。
14. 保存正式结果后的“先做下一项5分钟”回执会同时锁定回执来源和下一任务命令；点击前若回执或下一任务已经变化，只刷新提示，不会启动旧任务。
