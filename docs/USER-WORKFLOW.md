# 使用流程

## 早晨

1. 在“系统工具”中导入长期学习计划，先核对七天窗口、冲突和 P1 元数据差异，再确认应用。
2. 查看首页“今日最高优先级”和到期、逾期、未完成摘要。
3. 如当天时间明显不足，在“执行与欠账”中选择压缩日或保底日；确认后只调整今天至未来六天，不改变长期阶段模板。

## 学习过程中

1. 在今日任务上点击“设为当前任务”，再开始自由专注或 25 分钟番茄。
2. 切换任务前先结束或暂停当前计时，页面隐藏后需要回来手动继续。
3. 学完后每个任务只使用一个“记录实际结果”入口：
   - 英语分别记录单词和阅读；两个子任务都明确完成后，英语主任务才完成。
   - 政治记录章节、题量、正确数、K/M/L/W/C/G、薄弱点和下一起点。
   - 722/844 记录知识单元验收；输出训练记录题目、类型、用时、字数、闭卷情况和主要问题。
4. 纸质学习等未计时内容使用“补录学习时间”；训练、吃饭、休息等不计入学习总时长。
5. 需要重写或复盘时先生成候选，再人工确认进入正式复盘；不要用专注时长代替完成或掌握。

## 晚上

1. 处理今日到期与逾期复盘，未验收内容不要提升掌握等级。
2. 点击“扫描欠账”，对当前欠账选择安排、完成、拆小、降级或取消；超过三天的欠账必须明确处理。
3. 填写五项今日学习记录并保存，同一天重复保存会更新当天记录。
4. 导出“今日快照 JSON”或复制“总控回传版”。两项操作只读取数据，不修改学习记录。
5. 必要时从数据设置导出完整 JSON 备份。

## 周末

1. 展开“周统计”，查看本周有效学习天、计划完成率、D1 完成率、英语阅读、政治正确率、正式验收、输出、训练、模式和欠账。
2. 展开“Anki 候选”，从真实结果生成候选；逐张批准或拒绝，只导出已批准卡片。
3. 根据周统计警告处理超过三天欠账、连续保底日、低正确率和待重写输出。
4. 导出 TSV、CSV 或 JSON 后在 Anki 中试导入，确认字段和编码再正式使用。
