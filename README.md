# 考研学习任务面板

## 项目用途

这是一个用于日常考研复习管理的本地网页工具。它可以帮助你记录每天的学习任务、查看今日完成率、填写晚上复盘、查看最近 7 天复盘记录，并支持导出 TXT 和 JSON 备份。

这个项目不需要服务器，也不需要安装软件。只要用浏览器打开 `index.html` 就可以使用。

## 文件结构说明

```text
考研学习任务面板/
├── index.html   页面结构
├── style.css    页面样式
├── script.js    页面交互和数据保存逻辑
└── README.md    项目说明文档
```

## 核心文件分别负责什么

### index.html

`index.html` 负责网页内容和页面结构。

它决定页面上有哪些区域，例如：

- 顶部标题和考研倒计时
- 今日完成率
- 今日任务清单
- 上午、下午、晚上学习安排
- 晚上复盘区
- 本周学习统计
- 数据备份与恢复
- 历史复盘记录

### style.css

`style.css` 负责网页外观。

它控制页面的：

- 背景颜色
- 卡片样式
- 按钮样式
- 字体大小
- 间距
- 进度条
- 手机和平板上的排版

### script.js

`script.js` 负责网页功能。

它控制：

- 显示今天日期
- 计算考研倒计时
- 保存今日任务勾选状态
- 计算今日完成率
- 自动保存复盘输入内容
- 保存今日复盘到历史记录
- 渲染本周学习统计
- 导出 TXT
- 导出和导入 JSON 备份

## AI协作说明

本项目包含两个用于和 Codex 协作的说明文件：

- `AGENTS.md` 是给 Codex 的项目规则文件。以后修改项目时，必须遵守里面的工作规则、数据安全要求和开发边界。
- `PROMPTS.md` 是常用提示词模板库。新增功能、修 bug、样式优化、产品审查、Git 提交前检查时，可以优先从这里复制模板，再按实际需求修改。

简单来说：

- 想让 Codex 做事前，先参考 `PROMPTS.md` 组织需求。
- Codex 修改项目时，必须遵守 `AGENTS.md`。

## 如何在浏览器打开使用

方法很简单：

1. 找到项目文件夹。
2. 双击 `index.html`。
3. 如果没有自动用浏览器打开，可以右键 `index.html`，选择“打开方式”，再选择 Chrome、Edge 或其他浏览器。

打开后，页面会自动显示今天日期、考研倒计时、任务清单和历史记录。

## 如何保存今日复盘

1. 在“晚上复盘区”填写内容。
2. 可以填写：
   - 今天完成了什么
   - 哪些任务拖延了
   - 明天第一优先级
   - 今日状态评分
3. 点击“保存今日复盘”。
4. 保存后，这条记录会出现在“历史复盘记录”里。

复盘输入内容也会自动保存。即使暂时没有点击“保存今日复盘”，刷新页面后输入框内容通常也会保留。

## 如何导出 TXT

点击“导出为 TXT”按钮，可以导出最近 7 天的复盘记录。

TXT 文件适合阅读、打印、复制到文档里，内容包括：

- 日期
- 完成率
- 今日完成内容
- 拖延任务
- 明日第一优先级
- 状态评分

## 如何导出和导入 JSON 备份

### 导出 JSON 备份

点击“导出 JSON 备份”按钮，会下载一个 `.json` 文件。

JSON 备份会保存：

- 今日任务勾选状态
- 复盘输入内容
- 历史复盘记录
- 本周统计所依赖的历史数据

### 导入 JSON 备份

点击“导入 JSON 备份”按钮，选择之前导出的 `.json` 文件。

导入前浏览器会弹出确认提示，避免误覆盖当前数据。确认后，页面会恢复备份中的任务勾选、复盘输入和历史复盘记录。

## localStorage 数据保存机制说明

这个项目的数据保存在浏览器的 `localStorage` 里。

可以把 `localStorage` 理解成“浏览器给这个网页准备的小本地储物柜”。任务勾选、复盘输入、历史记录都会存在里面。

需要注意：

- 数据保存在当前浏览器里。
- 换一台电脑或换一个浏览器，通常看不到原来的数据。
- 清理浏览器缓存、网站数据或本地存储，可能会删除这些记录。
- 所以在清理浏览器数据前，一定先导出 JSON 备份。

## Git 常用命令

### git status

查看当前项目有没有文件被修改。

```bash
git status
```

常用简短版本：

```bash
git status --short
```

### git diff

查看文件具体改了什么。

```bash
git diff
```

只查看某个文件：

```bash
git diff script.js
```

### git add

把修改加入准备提交区。

```bash
git add README.md
```

一次添加多个文件：

```bash
git add index.html style.css script.js
```

### git commit

创建一次提交，记录当前修改。

```bash
git commit -m "add project readme"
```

### git restore

撤销还没有提交的修改。

撤销某个文件：

```bash
git restore script.js
```

注意：这个命令会丢弃文件里的未提交改动，使用前最好先运行 `git diff` 看清楚改了什么。

## 使用注意事项

- 不要在清理浏览器数据前忘记导出 JSON 备份。
- `导出 TXT` 主要用于阅读和归档。
- `导出 JSON 备份` 主要用于恢复数据。
- 如果要换电脑或换浏览器使用，建议先导出 JSON 备份，再在新浏览器里导入。
- 修改代码前，建议先运行 `git status`，确认当前项目状态。
